# Example outputs

Real `ARCHITECTURE.md` files generated by zinsight on popular open-source JS/TS projects. Each was produced by running:

```bash
npx zinsight --root <cloned-repo> --output examples/<project>/ARCHITECTURE.md
```

To regenerate all of them at once, run [`./scripts/generate-examples.sh`](../scripts/generate-examples.sh) from the repo root. It clones each upstream repo into a temp directory, runs the locally-built zinsight, and writes the output here.

These four were chosen for variety:

- **NestJS** — a large, decorator-heavy framework. Tests the analyser on real-world enterprise-style code.
- **Fastify** — a different backend framework with a hook/plugin model rather than decorators.
- **Hono** — a modern, lightweight framework for the edge. Tiny codebase, very different shape.
- **Express** — the classic. Older patterns, dynamic route registration, middleware stacks.

If you'd like another popular project added (Prisma, tRPC, Zod, Vite internals, etc.), open an issue or PR.

## What you should look at first

Don't read top-to-bottom. Each generated doc is structured so the **first 5 sections** are the orientation block — designed to be skimmed in 5 minutes:

1. **What This App Does** — one-paragraph summary
2. **At a Glance** — mini diagram of inbound/outbound traffic
3. **Core Concepts** — domain glossary
4. **Walking Through One Request** — request lifecycle for a representative endpoint (only emitted when there are real routes)
5. **Where State Lives** — DB / cache / cookies / env / FS

Everything below those is reference material — the full route list, schema ER diagram, dependency graph, hotspots from git, etc.

## How long did each take to generate?

Roughly 1-3 seconds per project. The bottleneck is `git clone --depth=1`, not the analysis.

## Notes on accuracy

zinsight uses pure AST analysis with heuristics. It will sometimes:

- Miss routes registered via unusual dynamic patterns
- Misclassify a folder's purpose if naming is non-standard
- Show "Unknown" auth method when the heuristic can't tell

These are filed as issues in the main repo. The orientation sections degrade gracefully — when zinsight can't infer something, it omits the section rather than fabricating.
